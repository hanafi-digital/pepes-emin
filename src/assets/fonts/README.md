Self-hosted, latin-subset woff2 files (SIL Open Font License), vendored
directly rather than kept as an npm dependency.

Source: `@fontsource-variable/bricolage-grotesque@5.3.0` and
`@fontsource/newsreader@5.3.0` (fontsource.org). To update, install those
packages temporarily, copy the files below from their `files/` directory,
then uninstall the packages again — see git history for this file for the exact
files copied.

- `bricolage-grotesque-latin-variable.woff2` — from
  `bricolage-grotesque-latin-standard-normal.woff2` (weight 200–800, normal style)
- `newsreader-latin-400.woff2` — weight 400, normal
- `newsreader-latin-400-italic.woff2` — weight 400, italic
- `newsreader-latin-600.woff2` — weight 600, normal
